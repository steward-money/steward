## What's new

Fixes for the five issues filed after 0.1.1, two gateway fixes, and current dependencies.

### Security

- A wrong password takes the same work whether or not the username exists, so timing a sign-in doesn't show which names have accounts.
- Wrong tries count by the name as typed, so the count doesn't show that a username and an email belong to one account. A device that has signed in to the account gets five tries for the account in all.
- A session cookie from 0.1.0 no longer signs anyone in on an https install, so a cookie another host on the domain plants under that name is worth nothing.
- The gateway charges the monthly budget only for what Anthropic may bill. When it can't tell whether a request went out, it stops the turn instead of guessing, and an answer cut short is never shown as complete.
- The gateway's Anthropic library is 2.8, with its tracing turned off and every header it sends pinned.

### Privacy

- The gateway now replaces a person's name its local model finds in an approved store row with `[name]`, unless the manager ticked that row. This happens on the gateway, before anything goes to Claude. [Privacy](https://github.com/steward-money/steward/blob/v0.1.2/docs/explanations/privacy.md#which-store-rows-hide-a-name) lists which rows can still keep a name.

### Thoughtfulness

- Card lines that start "PURCHASE AUTHORIZED ON", as Wells Fargo writes them, are named by their store. Before, every card purchase at that bank was one payee, so marking one charge as expected quieted all of them.
- Home, Plan and Taxes name a saved plan by the household's day, so a device in another time zone shows the same date.
- About 50 status lines, such as "Saved", "Undone" and the payoff date, are now read by screen readers when they appear. Lines that only show what's saved stay quiet when a page opens.
- Node 26, TypeScript 7 and Vite 8 build the web app, and the first download is smaller (186.0 to 180.6 KB). The proxy runs Caddy 2.11.9 and the gateway's Ollama 0.40.16.

## Before you upgrade

- Upgrade Steward and the gateway together. They now speak protocol 3, and until both run 0.1.2, Ask can't answer. A GPU gateway builds from your clone, so run `git pull` there and rebuild it, as the [upgrade guide](https://github.com/steward-money/steward/blob/v0.1.2/docs/guides/upgrade.md) says in step 2.
- If you use an https address and haven't signed in since 0.1.0, you'll be asked to sign in once.
- On first start, a migration re-keys set-asides that were made for Wells Fargo card lines. There's nothing to do.

## Verify the images

Install cosign 3 or newer, and jq. Cosign 2 can't read these signatures. Then check each image against the release workflow's identity:

```
cosign verify ghcr.io/steward-money/steward:0.1.2 \
  --certificate-identity-regexp '^https://github\.com/steward-money/steward/\.github/workflows/release\.yml@refs/tags/v' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  | jq -r '.[0].critical.image."docker-manifest-digest"'
```

It prints a digest only when the check passes. Run it again with `steward-proxy` and `steward-gateway` in place of `steward`. The release's digests are listed below, and the [upgrade guide](https://github.com/steward-money/steward/blob/v0.1.2/docs/guides/upgrade.md#verify-the-images) shows how to pull by digest.
