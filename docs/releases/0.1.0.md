## What's new

Steward is a self-hosted household finance app: spending, accounts, Review, a retirement plan, taxes and Ask, for you and the people you look after. 0.1.0 is for US households of one or two adults, on x86_64 Linux with Docker. Transactions come from SimpleFIN or files, and the gateway for Ask is optional.

### Security

- Your books are encrypted at rest with SQLCipher, using AES-256. The key can live on its own mount, and backups never hold it.
- PDF statements are opened in a sandbox.
- There's no open sign-up. The first person comes from a one-time setup link. Passkeys work alongside passwords.
- The images are signed by the release workflow, with no stored key, and come with an SBOM and provenance.

### Privacy

- Steward never connects to Claude itself. Only your gateway does.
- Account and payee names go to Claude as aliases such as "Account 1", except store names in rows a manager approves. A model on the gateway looks for other names and can miss one.
- Claude never receives your notes or account numbers.
- The sent log shows every part of your data that was sent.
- Steward connects only to the services you set up.

### Thoughtfulness

- Review sorts, Snooze, Ignore, notes, and Profile and spending changes can be undone for 15 minutes. Every delete has an Undo or a clear confirm.
- No cheers beside bad news.
- Dark mode and phones work, and every screen passes automated accessibility checks.

## Before you upgrade

This is the first release. To install it, follow [Install for your household](https://github.com/steward-money/steward/blob/v0.1.0/docs/quickstart/install.md).

## Verify the images

Install cosign 3 or newer, and jq. Cosign 2 can't read these signatures. Then check each image against the release workflow's identity:

```
cosign verify ghcr.io/steward-money/steward:0.1.0 \
  --certificate-identity-regexp '^https://github\.com/steward-money/steward/\.github/workflows/release\.yml@refs/tags/v' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  | jq -r '.[0].critical.image."docker-manifest-digest"'
```

It prints a digest only when the check passes. Run it again with `steward-proxy` and `steward-gateway` in place of `steward`. The release's digests are listed below, and the [upgrade guide](https://github.com/steward-money/steward/blob/v0.1.0/docs/guides/upgrade.md#verify-the-images) shows how to pull by digest.
